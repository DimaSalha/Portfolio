# Web Development Demo Projects

This folder contains practice/demo websites built with semantic HTML, responsive CSS, and lightweight JavaScript where needed.

## Projects
- **Coffee Shop Landing Page** — a responsive fictional café website with menu highlights, opening hours, and contact details.
- **Creative Studio Landing Page** — a responsive agency website presenting services, sample work, and a contact call to action.
- **Product Landing Page** — a responsive product showcase with features, pricing cards, and FAQ.

## Important
These are demonstration projects for portfolio purposes, not paid client projects. Update all fictional business details and contact information before real-world use. Any third-party assets or fonts are credited in the individual project files.
